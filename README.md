PROJETO 1 — Plataforma DentistaTech
🔗 Link do site: https://dentistatech.com.br/
🔗 Link do repositório: https://github.com/RoberioFagundes/dentistatech

Descrição: Sistema Web completo de gestão integrada para consultórios 
odontológicos. Desenvolvimento full-stack com foco em usabilidade e 
fluxos operacionais reais.

Funcionalidades:
• Agenda e acompanhamento de atendimentos diários
• Orçamentos com cálculos automáticos e descontos
• Controle de pagamentos por diferentes formas
• Cadastro de pacientes com histórico completo
• Interface responsiva (computador, tablet, celular)
• Navegação modular por perfis de acesso

Tecnologias:
• Frontend: HTML5, CSS3/SCSS, JavaScript, Bootstrap 5
• Backend: PHP 8.x, Laravel 10.x
• Banco de Dados: MySQL 8.x, Eloquent ORM
• Ferramentas: Git, Figma/Adobe XD
• Repositório público com código-fonte documentado

Período de desenvolvimento: Janeiro/2025 → em operação
